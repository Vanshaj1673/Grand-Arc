# Project: Grand Arc Sales Deck

## What This Is
A high-end, cinematic, and immersive browser-based sales deck for "Grand Arc", a flagship shopping mall destination in New Delhi. This is not a standard website but a video-first storytelling experience designed to engage high-end luxury brands and partners.

## Core Value
To provide an emotional and visceral "walkthrough" of the mall's grandeur before it is even visited, using state-of-the-art web technology to reflect the premium nature of the development.

## Success Criteria
- **Performance**: 90+ Lighthouse scores across the board.
- **Visuals**: Premium, "wow" factor aesthetics with smooth 60fps transitions.
- **Engagement**: Strategic non-linear navigation that allows stakeholders to explore different facets (Retail, Dining, Entertainment) at their own pace.
- **Responsive**: Flawless experience across desktop, tablet, and mobile.

## Requirements

### Validated
- ✓ **Smooth Scrolling**: Lenis integration for refined scroll feel.
- ✓ **Design System**: SCSS token-based system with premium "Onyx & Gold" palette.
- ✓ **Section Architecture**: Functional landing page sections (Hero, Why, Retail, Dining, etc.).
- ✓ **Cinematic Hero**: Video-first entry sequence with GSAP reveal.

### Active
- [ ] **Interactive Map/Floorplan**: A non-linear way to explore the mall's layout.
- [ ] **Dynamic Content Overlays**: More detailed "pop-up" information for specific brands or areas.
- [ ] **Performance Optimization**: Lazy-loading videos and assets for optimal speed.
- [ ] **Non-linear Navigation Refinement**: Enhancing the "Sales Deck" feel vs a standard scroll.

### Out of Scope
- **Backend/CMS**: Currently sticking to a highly optimized static build for maximum performance.
- **E-commerce**: This is a sales deck, not a shopping portal.

## Key Decisions
| Decision | Rationale | Outcome |
|----------|-----------|---------|
| GSAP + Lenis | Best-in-class tools for cinematic web animations and scroll control. | Implemented |
| SCSS Modules | Scoped styling without the overhead of utility-first complexity for custom animations. | Implemented |
| Video-First | Emotional engagement is prioritized over static images. | Implemented |
