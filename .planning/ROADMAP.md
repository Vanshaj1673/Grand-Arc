# Roadmap: Grand Arc Sales Deck

## Milestone 1: The Immersive Experience (v1.0)

Goal: Deliver a premium, cinematic, and interactive sales deck that wows stakeholders.

### Phase 1: Refinement & Cinematic Polish
Goal: Elevate the current baseline to "premium" status with refined timings and flawless transitions.
- [ ] Review all section entry animations (GSAP).
- [ ] Ensure consistent typography and spacing across all sections.
- [ ] Implement smooth section transitions/parallax effects.
- [ ] Performance check for video assets.

### Phase 2: Interactive Deck Navigation
Goal: Move from a "landing page" feel to a "sales deck" experience.
- [ ] Implement a non-linear navigation menu (Quick jump to Retail, Dining, etc.).
- [ ] Add interactive indicators for current scroll progress.
- [ ] Explore "Story Mode" vs "Explore Mode" navigation.

### Phase 3: Immersive Content Overlays
Goal: Add depth to the deck with detailed information layers.
- [ ] Design and implement "Luxury Brand" spotlights.
- [ ] Add interactive floorplan/map overview (high-level).
- [ ] Implement "Detailed View" modals for key mall features.

### Phase 4: Performance & Launch Readiness
Goal: Guarantee the 90+ Lighthouse score and production stability.
- [ ] Comprehensive asset optimization (WebP/WebM).
- [ ] Implement lazy loading for off-screen sections/videos.
- [ ] Final Lighthouse audit and performance fixes.
- [ ] Cross-browser and cross-device verification.
