An immersive, high-fidelity digital experience designed to showcase the **Grand Arc** mall project. This sales deck combines cinematic storytelling with fluid, non-linear navigation to provide potential investors and tenants with a premium preview of the future of retail.

## ✨ Core Experience

- **Cinematic Storytelling:** Fluid transitions and scroll-triggered animations powered by **GSAP**.
- **Immersive Navigation:** A bespoke **DeckNav** system allowing users to jump between key value propositions seamlessly.
- **Premium Aesthetics:** Atmospheric grain overlays, custom magnetic cursors, and spotlight effects for a high-end feel.
- **Performance Optimized:** Lazy-loaded high-definition video backgrounds and efficient component architecture for a smooth 90+ Lighthouse score experience.
- **Fluid Motion:** Integrated **Lenis** smooth scrolling for a natural, tactile feel across all devices.

## 🏗️ Architecture

The project is built with a modular, section-based architecture for maximum scalability:

- **Hero:** Impactful intro with high-cinematic visuals.
- **Why Section:** Core value propositions and project vision.
- **Themed Zones:** Deep dives into **Retail**, **Dining**, **Entertainment**, and **Events**.
- **Interactive Floorplans:** Spatial orientation and leasing opportunities.
- **CTA:** Seamless lead generation and contact interface.

## 🛠️ Tech Stack

- **Frontend:** React 19 + Vite
- **Animations:** GSAP (GreenSock Animation Platform) + ScrollTrigger
- **Styling:** Tailwind CSS 4 + SCSS Modules
- **Scroll Engine:** Lenis Smooth Scroll
- **Interactions:** Swiper.js for premium carousels
- **Quality:** ESLint + Prettier

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Vanshaj1673/Grand-Arc.git
   ```
2. Navigate to the project directory:
   ```bash
   cd mall-deck
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

### Development

Start the development server:
```bash
npm run dev
```

### Build

Create a production-ready bundle:
```bash
npm run build
```
